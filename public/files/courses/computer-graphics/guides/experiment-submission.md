# 2026秋《计算机图形学》实验提交规范

## 一、提交时间

1. 实验一般在任务发布后 **一周内**完成并提交。本课程上课时间为周一，因此常规截止时间统一为**下一周周一 00:00（零时）**。
2. 例如，9 月 21 日（周一）发布的实验，截止时间为 **9 月 28 日（周一）00:00**，即应在 **9 月 27 日（周日）结束前**完成两种渠道的提交。**不要误认为可以在截止日周一的白天提交。**
3. 如有节假日或其他特殊安排，以该次实验在课程平台公布的截止时间为准。
4. 建议提前完成提交，预留邮件发送、文件上传和压缩包检查所需时间。

## 三、ZIP 压缩包内部目录规范

实验使用 WebGL 实现。压缩包解压后，应直接看到“实验x_学号”目录，进入后有入口文件 `index.html` 和资源目录 `common/`、`js/`，具体结构如下（根据原实验说明中的目录图整理）：

```text
实验X_学号
├── common/
│   ├── gl-matrix-min.js
│   ├── initShaders.js
│   └── webgl-utils.js
├── index.html
└── js/
    └── triangle.js
```

以上文件名沿用原图作为**示例**，实际应包含运行本次实验所需的工具库与自己的程序文件，并在`index.html`中提供正确的相对路径链接。

**目录及文件放置规则：**

1. **`index.html` 必须位于压缩包根目录**，作为实验入口，能够打开并展示实验作品或任务导航。
2. `common/` 存放 WebGL 工具库等公共依赖，例如 `gl-matrix-min.js`、`initShaders.js`、`webgl-utils.js`。
3. `js/` 存放本人编写的 JavaScript 程序，例如 `triangle.js`。
4. 如实验使用图片、模型等其他必要资源，应将这些文件一并放入压缩包，使用正确的**相对路径**引用，保证解压后可独立运行；不要引用仅存在于本人电脑上的绝对路径。
5. 归档前在本地解压检查，确认能找到入口文件、依赖文件齐全，页面与交互功能能够正常运行。

### 一次实验包含多个任务时

每个任务分别建立 HTML 页面，以任务序号命名，例如 `task1.html`、`task2.html`；在根目录 `index.html` 中放置通往各任务页面的明显链接。示例：

```text
实验X_学号
├── common/
│   ├── gl-matrix-min.js
│   ├── initShaders.js
│   └── webgl-utils.js
├── index.html          # 实验首页：包含 task1.html、task2.html 的链接
├── task1.html
├── task2.html
└── js/
    ├── task1.js
    └── task2.js
```

实际任务页和程序文件数量可按该次实验要求调整，但须保留根目录入口与清晰的任务导航。
