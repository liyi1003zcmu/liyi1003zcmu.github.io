#sec-4-3
Normalization

为什么要把任意观察体映射到规范立方体？

不同程序和模型可以使用不同世界单位；GPU裁剪和后续处理需要统一的规范范围。

视空间范围 [l,r]→平移 + 缩放→规范范围 [−1,1]
xndc = 2(x − l)/(r − l) − 1这里以正交投影的X分量为例说明；Y、Z按相应边界映射。
课堂快速代入：x=l时得到−1；x=r时得到1；中点对应0。

#sec-5-2
Similarity of Triangles

近大远小来自相似三角形

相机位于原点、沿负Z方向看，在z = −f平面投影。由相似三角形可得到：

x′ = f · x/(−z)　　y′ = f · y/(−z)

近处：z=−2

取f=1、x=1，则x′=0.5。

远处：z=−4

取f=1、x=1，则x′=0.25。

学生应能解释：分母随距离增加，投影后的坐标幅度变小。
#sec-5-3
Homogeneous Coordinates

非线性透视关系，为什么仍可用矩阵？

三维点的齐次表示→4×4 投影矩阵→裁剪坐标 (xc,yc,zc,wc)→除以 wc
xndc = xc/wc，yndc = yc/wc
透视投影矩阵利用齐次分量表示深度相关的变换；真正的除法由顶点着色器之后的流水线阶段完成。

#sec-5-5
Perspective Parameters

四个参数，分别控制取景和裁剪

参数 含义 改变后的典型效果
fovy 垂直视角 变大 → 视野更广、物体通常更小
aspect 宽高比 决定水平与垂直显示范围比例
near 近裁剪距离 太近的几何可能被裁剪
far 远裁剪距离 太远的几何可能被裁剪 
mat4.perspective(projectionMatrix,
  Math.PI / 4, canvas.width / canvas.height,
  0.1, 100.0);
gl-matrix中fovy单位是弧度；通常要求0 < near < far。

Minimal Vertex Shader

WebGL2：在顶点着色器中形成裁剪坐标

#version 300 es
in vec4 aPosition;
uniform mat4 uModelMatrix;
uniform mat4 uViewMatrix;
uniform mat4 uProjectionMatrix;

void main() {
  gl_Position = uProjectionMatrix *
                uViewMatrix * uModelMatrix * aPosition;
}
gl_Position输出齐次裁剪空间坐标；透视除法和视口变换由后续图形流水线完成。
#sec-6-5
Clipping ≠ Occlusion

“看不到”有两种不同原因

超出视见体 → 裁剪

几何不在投影定义的可见范围内，即使前方没有其他物体也可能被裁剪。

位于后方 → 遮挡

处于视见体内的表面可能被其他表面挡住，通常利用深度测试解决。

gl.enable(gl.DEPTH_TEST);
gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);
本节只建立区分；背面剔除、深度精度、阴影贴图等列为教材延伸。
