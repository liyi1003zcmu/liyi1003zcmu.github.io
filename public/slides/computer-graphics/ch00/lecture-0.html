Course overview

这是一门什么样的课？

FOUNDATION

图形学基本概念与应用

理解计算机如何描述、变换、观察并绘制二维与三维对象。

PROGRAMMABLE GPU

可编程着色器

以现代可编程流水线为核心，理解 Vertex Shader 与 Fragment Shader。

WEB GRAPHICS

WebGL 2.0

使用现代 Web 技术完成交互式图形程序设计与实验。

课程不是学习一个“绘图软件”，而是学习图像生成背后的模型、算法、系统与程序设计方法。

Course content · Classification

课程内容规划：重点内容与介绍性内容

CORE MODULES · 重点内容

一至七章 及 第十二章

课程核心与考核重点：深入理解图形学数学模型、渲染管线底层原理与着色器编程实现。

  • 第1章 图形系统和模型：软硬件体系、虚拟照相机、可编程流水线架构
  • 第2章 图形学编程：Sierpinski镂垫、WebGL API、着色器程序与图元属性
  • 第3章 交互和动画：事件驱动输入、交互设计、动画渲染循环与对象拾取
  • 第4章 几何对象和变换：坐标系标架、仿射变换、齐次坐标、变换级联与四元数
  • 第5章 观察：相机定位、观察矩阵、平行/透视投影变换与规范化视见体
  • 第6章 光照和着色：Phong光照模型、材质与光源、法向量计算、片元着色
  • 第7章 纹理映射：二维纹理坐标、采样与滤波、环境映射与凹凸贴图
  • 第12章 从几何到像素：绘制流水线底层、图元裁剪、多边形光栅化、Z-Buffer与反走样
EXTENDED MODULES · 介绍性内容

第八章 及 第九章

拓宽视野与综合设计：了解现代图形系统高阶特性与复杂三维场景组织管理方法。

  • 第8章 使用帧缓存：颜色与深度缓存、Alpha混合技术、帧缓存对象（FBO）离屏渲染、多重绘制、图像后处理滤波与拾取
  • 第9章 层级建模方法：符号与实例变换、机器人手臂模型、树结构与递归遍历、场景图（Scene Graph）构建与运动控制
教学指引

重点章节要求“深入原理、独立编程、调试分析”；介绍性章节重在“理解思想、了解系统能力、善于查阅与应用”。
