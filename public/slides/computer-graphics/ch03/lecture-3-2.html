#sec-3-2

坐标系不一样：不能直接使用鼠标坐标

浏览器窗口坐标以左上角为原点（Y轴向下）；WebGL 裁剪空间 (NDC) 以中心为原点，范围映射在 [-1, 1] 且 Y轴向上。

坐标映射公式 (Screen → NDC)

设 Canvas 宽度为 w，高度为 h，鼠标在 Canvas 内的像素坐标为 (xw, yw)：

X 轴映射： x = -1 + 2 · xw / w
Y 轴映射： y = -1 + 2 · (h - yw) / h

核心要点：Y 轴方向反转（h - yw）是完成屏幕像素到 GPU 渲染坐标转换的关键。

#sec-3-4

更稳健的Canvas坐标转换

如果Canvas不在页面左上角，直接用 event.clientX / canvas.width 会产生偏移。 

function pointerToNDC(event, canvas) {
    const rect = canvas.getBoundingClientRect();

    const xCanvas = (event.clientX - rect.left) * canvas.width / rect.width;
    const yCanvas = (event.clientY - rect.top) * canvas.height / rect.height;

    const x = 2 * xCanvas / canvas.width - 1;
    const y = 1 - 2 * yCanvas / canvas.height;

    return [x, y];
}

#sec-4-1

点击怎样变成GPU中的新顶点？

坐标转换之后，得到的是WebGL可用的位置数据。接下来把它写入Buffer，并在下一次绘制中显示出来。

Click→NDC vec2→bufferSubData→index++→drawArrays 
let index = 0;

canvas.addEventListener("click", function(event) {
    const [x, y] = pointerToNDC(event, canvas);
    const point = new Float32Array([x, y]);

    gl.bindBuffer(gl.ARRAY_BUFFER, vBuffer);
    gl.bufferSubData(gl.ARRAY_BUFFER, 2 * 4 * index, point);
    index++;
});

function render() {
    gl.clear(gl.COLOR_BUFFER_BIT);
    gl.drawArrays(gl.POINTS, 0, index);
    requestAnimationFrame(render);
}
#sec-4-2

交互式程序必须保存跨事件状态

一次点击只能提供一个位置。绘制矩形需要两次点击，因此程序必须记住第一次点击的位置。

第一次点击

保存P1，不立即形成矩形。

firstPoint = [x, y];
waitingSecond = true;

第二次点击

得到P2，计算另外两个顶点，上传4个顶点。

makeRectangle(firstPoint, [x, y]);
waitingSecond = false;
交互式建模的本质：事件不断到来，程序状态不断积累，绘制结果不断更新。

#sec-5-2

Picking（对象拾取）的三种常见思想

前向渲染从对象绘制到像素；反向拾取要从鼠标点击的屏幕像素锁定对应图形对象。

Method 01

包围盒法 (Bounding Box)

核心思想：先用简单的包围矩形/轴对齐包围盒 (AABB) 做碰撞判定。
特点：计算速度快、易于实现，适合二维与粗粒度筛选。

🖼️ 查看包围盒法示意图 ↗
Method 02

颜色 ID 法 (Color-ID Offscreen)

核心思想：在后台帧缓冲给每个对象绘制唯一编码颜色，用 gl.readPixels 读取像素值识别对象。
特点：硬件加速、像素级精确，适合复杂几何。

🖼️ 查看颜色ID法示意图 ↗
Method 03

射线拾取法 (Ray Casting)

核心思想：从视点经过鼠标点击点穿过屏幕生成一条三维射线，计算射线与场景网格的求交。
特点：数学完备，适合三维空间精确选择。

🖼️ 查看射线拾取法示意图 ↗
