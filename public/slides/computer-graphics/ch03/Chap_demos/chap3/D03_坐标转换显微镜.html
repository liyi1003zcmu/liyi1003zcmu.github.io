坐标转换流水线 (Pipeline)
1Mouse Event 视口坐标 (Y向下)
clientX = -- px clientY = -- px
原点在浏览器视口左上角，y 轴向下增大
↓ 减去 Canvas 页面相对偏移 (BoundingClientRect)
2Canvas CSS 坐标 元素局部坐标
x_css = -- px y_css = -- px
x_css = clientX - rect.left
y_css = clientY - rect.top
↓ 乘以像素密度缩放比 (Buffer / CSS Size)
3Drawing Buffer 像素坐标 1 : 1
x_buf = -- px y_buf = -- px
x_buf = x_css × (canvas.width / rect.width)
y_buf = y_css × (canvas.height / rect.height)
↓ 映射到 [-1, 1] 并翻转 Y 轴
4WebGL NDC 归一化设备坐标 核心映射
x_ndc = -- y_ndc = --
x_ndc = 2.0 × (x_buf / canvas.width) - 1.0
y_ndc = 1.0 - 2.0 × (y_buf / canvas.height) /* Y 轴翻转 */
↓ 顶点着色器 gl_Position 输出
5GPU 栅格化绘制 (Draw Point) 精确重合
gl_Position = vec4(x_ndc, y_ndc, 0.0, 1.0);
通过视口变换 (Viewport Transform) 栅格化为屏幕像素
