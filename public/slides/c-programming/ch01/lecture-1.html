程序与程序设计语言

程序

人们为解决某种问题，用计算机可以识别的代码，编排的一系列加工步骤。

程序执行过程，本质上是对程序所表达的数据进行处理的过程。

程序设计语言

提供一种表达数据与处理数据的功能，要求程序员按照语言规范编程。

程序与指令

指令

计算机最基本的功能，例如实现一次加法运算，或实现一次大小判别。

指令系统

计算机所能实现的指令的集合。

程序

为完成某个任务而编写的一系列计算机指令的有序组合。

类比：菜谱也是一组有序步骤。

用“菜谱”理解程序

程序名：番茄炒蛋

指令1：拿出两个鸡蛋

指令2：将鸡蛋打入碗中并搅拌

指令3：切番茄

指令4：加热、翻炒、调味

计算机程序比菜谱更严格：每一步都必须精确。

虚拟计算机指令系统

例：编写程序，分别求和与乘积。约定字母表示内存单元，0、1 等数字表示常量；虚拟计算机定义7条指令：

  • Input X：将当前输入数据存储到内存 X 单元
  • Output X：将内存 X 单元的数据输出
  • Add X Y Z：将操作数 X 与 Y 的值相加，结果存储到内存 Z
  • Sub X Y Z：将操作数 X 与 Y 的值相减，结果存储到内存 Z
  • BranchEq X Y P：若操作数 X 与 Y 的值相等，跳转到 P 处执行
  • Jump Q：程序跳转到 Q 处执行
  • Set X Y：将操作数 X 的值存储到内存 Y

虚拟程序：输入A、B、C，求A+B+C


Input A;     输入第1个数据到A
Input B;     输入第2个数据到B
Input C;     输入第3个数据到C
Add A B D;   D = A + B
Add C D D;   D = C + D
Output D;    输出D

{
    // 函数体：写具体要执行的语句

}

C程序由一个或多个函数组成，main 是主函数，有且只有一个。

例1-1：求阶乘问题

输入一个正整数 n，输出 n!。例如输入 4，输出 24。 


#include <stdio.h>
int factorial(int n);

int main(void)
{
    int n, result;
    scanf("%d", &n);
    result = factorial(n);
    printf("%d\n", result);
    return 0;
}

int factorial(int n)
{
    int i, fact = 1;
    for(i = 1; i <= n; i++)
    {
        fact = fact * i;
    }
    return fact;
}

阶乘程序：先读懂，不急着写

  • 函数：C程序由函数组成，main 是入口，factorial 是自定义函数
  • 变量：int n, result; 在内存中准备空间保存整数
  • 函数声明：提前告诉 main 后面有一个 factorial 函数
  • 输入：scanf("%d", &n) 从键盘读取整数
  • 循环：for 反复执行乘法，实现 n!
本页可作为“阅读示例”，不必在第一次课完全讲透。

问题求解示例

问题：求 1–100 之间所有偶数的和

先不要急着写代码，先分析问题。

问题分析与算法分析

  • 思路 → 算法：先有解决问题的思路，再形成明确步骤
  • 算法：一组明确的解决问题的步骤，它产生结果，并能在有限时间内终止
  • 算法描述：自然语言、伪代码、流程图

思路和算法

  • 明确问题：在范围 1–100 内，找到满足条件“偶数”的整数，并求累加和
  • 设置变量：用 sum 保存累加结果，初始值为 0
  • 重复检查：依次查看每个整数 i
  • 条件判断：如果 i 是偶数，就执行 sum = sum + i;

算法描述：流程图

从算法到程序：先看整体


#include <stdio.h>

int main(void)
{
    int i, sum = 0;

    for(i = 1; i <= 100; i++)
    {
        if(i % 2 == 0)
        {
            sum = sum + i;
        }
    }

    printf("%d\n", sum);
    return 0;
}

第一次课只看清楚“输入/处理/输出”和“顺序/分支/循环”如何配合。

问题延伸：同一个结构可以解决更多问题

从固定范围到输入范围

把 1–100 改为 1–n，需要增加输入，并用 n 控制循环终点。

从偶数和到奇数和

把条件 i % 2 == 0 改为 i % 2 != 0。

思考：如何计算从 1 到 n 之间的奇数之和？

问题延伸：让AI帮助，但不替代思考

推荐问法：
“我已经知道如何求1到100之间偶数的和。现在想改成求1到n之间奇数的和。请不要直接给完整代码，先提示我需要修改哪些地方，并帮我设计3组测试数据。”

这比直接问“给我答案”更能帮助学习。

本章要点总结

  • 程序：为解决问题而设计的一系列指令或步骤。
  • 程序设计语言：用于表达数据、处理过程、输入输出和模块化组织。
  • C程序框架：由一个或多个函数组成，必须有 main 主函数。
  • 结构化控制：顺序、分支、循环是程序组织的基本方式。
  • 编译运行：源程序需要经过编译、链接，才能形成可执行程序。
  • 问题求解：核心是先分析问题和设计算法，再编写、运行和验证程序。
  • AI协作：AI可以辅助，但不能替代理解、判断、测试和责任。
