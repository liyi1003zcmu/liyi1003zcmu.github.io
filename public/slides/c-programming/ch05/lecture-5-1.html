社区慢病随访记录

居民体检采集：体重 70.0 kg，身高 1.75 m。

背景：体质指数（BMI）是社区高血压、糖尿病等慢病随访建档的核心指标。

体质指数计算公式

统一按标准公式计算：

70.0 ÷ (1.75 × 1.75) ≈ 22.86

double bmi1 = 70.0 / (1.75 * 1.75);

double bmi2 = 82.0 / (1.80 * 1.80);

double bmi3 = 55.0 / (1.60 * 1.60);
思考：如果社区有数十位慢病居民随访数据，或者要统一增加“身高不能为0或负数”的合法性检查，直接复制表达式会遇到什么困难？

接口设计问题 在本例中的约定
1. 函数叫什么名字？ calcBMI（名称清晰表达单一职责）
2. 需要调用者提供什么输入（形参）？ double weight（体重/kg）、double height（身高/m）
3. 向调用者交还什么结果（返回类型）？ double（计算出的体质指数 BMI）
4. 输入不合法时如何响应？ 若 weight <= 0 或 height <= 0，统一返回错误标识 -1.0

第一次定义函数：把规则写成独立模块

double calcBMI(double weight, double height)

{

    if (weight <= 0 || height <= 0)

        return -1.0;

    return weight / (height * height);

}

函数首部（Header）

  • 返回类型：double（与返回值类型一致）
  • 函数名：calcBMI
  • 形参表：(double weight, double height)，每个参数都必须单独写明类型

函数体（Body）

  • 先做边界卫语句校验，拒绝非正体重与非正身高（防止除以0）
  • 再用平方除法计算，通过 return 把结果交还调用者
9:30—12:00。提醒学生：形参列表不能写成 (double weight, height)，每个形参都必须声明类型；函数首部后面没有分号。

main 怎样使用一个自定义函数？

#include <stdio.h>



double calcBMI(double weight, double height);   /* 1. Function prototype */



int main(void)

{

    double bmi = calcBMI(70.0, 1.75);           /* 2. Function call */

    printf("BMI = %.2f\n", bmi);

    return 0;

}



double calcBMI(double weight, double height)    /* 3. Function definition */

{

    if (weight <= 0 || height <= 0)

        return -1.0;

    return weight / (height * height);

}

函数声明

告诉编译器函数的返回类型、名称和参数类型，末尾有分号。

函数调用

在 main 中给出实参 (70.0, 1.75)，启动函数并接收返回值。

函数定义

真正实现计算逻辑的代码块，首部末尾无分号。

5.1 / 参数传递与执行流
调用函数时，
数据是怎样进出的？

控制流跳转 实参与形参 单向值传递 return 机制

一次函数调用的执行路线

1. main 暂停
遇到 calcBMI(70.0, 1.75)
→
2. 实参复制给形参
70.0 → weight
1.75 → height
→
3. 执行函数体
算出 22.86
→
4. return 返回
回到调用处赋给 bmi
函数执行完毕后，程序不会从头重新运行 main，而是精确回到刚才调用它的位置继续往下走。
16:00—17:30。让学生用手指跟踪代码执行位置：main 调用处 → 函数首部 → 函数体 return → main 调用处下一行。

认知冲突：在函数里修改形参，会影响原变量吗？

void tryChange(double x)

{

    x = 100.0;

}



int main(void)

{

    double weight = 70.0;

    tryChange(weight);

    printf("%.1f\n", weight);

    return 0;

}

先预测再解释：屏幕最终打印 70.0 还是 100.0？

main 的变量区

weight 始终保存在 main 自己的内存单元中，值为 70.0。

tryChange 的形参区

形参 x 只是复制了一份 70.0 的副本；x = 100.0 只改了副本，函数结束即销毁。

17:30—19:30。这是初学者最高频的误区之一。通过“复印件上涂改不影响原件”帮助建立直觉。

值传递（Pass by Value）的规则与边界

实参（Actual Argument）

  • 出现在函数调用圆括号中
  • 可以是常量、变量或表达式，如 calcBMI(w + 2.5, 1.75)
  • 调用时必须已经有确定的值

形参（Formal Parameter）

  • 出现在函数定义首部圆括号中
  • 必须是变量名，用来接收实参传来的值
  • 仅在函数被调用期间分配内存，返回后释放
值传递边界说明：本节讨论普通数值变量（int、double、char）作为参数，数据单向从实参传给形参；后续学习指针与数组时，再讨论如何让函数修改调用者的数据。

教材例5-1 题面描述

📋 题目要求

输入圆柱体的半径 \(r\) 和高 \(h\)，计算并输出圆柱体的体积 \(V = \pi r^2 h\)。
要求定义和调用函数 cylinder(r, h) 计算圆柱体的体积。

\[V = \pi r^2 h\]

教材例5-1：圆柱体体积函数实现

#include <stdio.h>

double cylinder(double r, double h);



int main(void)

{

    double height, radius, volume;

    scanf("%lf%lf", &radius, &height);

    volume = cylinder(radius, height);

    printf("Volume = %.3f\n", volume);

    return 0;

}



double cylinder(double r, double h)

{

    double result;

    result = 3.1415926 * r * r * h;

    return result;

}

结构对照与检验

  • 对照 calcBMI：同样是“两个数值参数 → 公式计算 → 返回 double”。
  • 参数对应：实参 radius 传给形参 r，height 传给 h，按位置顺序一一对应。
  • 预测结果：输入 2.0 3.0，输出 Volume = 37.699。
21:00—23:00。强调实参与形参名字可以不同（radius 对 r，height 对 h），只按位置顺序传递值。

教材例5-2 题面描述与几何分解

📋 教材例5-2 题目要求

将一个五边形分割成三个三角形（如右图），输入各边长 \(a_1 \sim a_7\)，定义并调用计算三角形面积的函数 area(x, y, z)，求五边形面积。

海伦-秦九韶公式

已知三角形三边 \(x, y, z\)，半周长 \(p = \frac{x+y+z}{2}\)：

\[\text{area} = \sqrt{p(p-x)(p-y)(p-z)}\]

教材例5-2：一个函数，被三组数据重复调用

#include <stdio.h>

#include <math.h>



double area(double x, double y, double z);



int main(void)

{

    double a1, a2, a3, a4, a5, a6, a7, s;

    scanf("%lf%lf%lf%lf%lf%lf%lf", &a1, &a2, &a3, &a4, &a5, &a6, &a7);

    s = area(a1, a5, a6) + area(a4, a6, a7) + area(a2, a3, a7);

    printf("The area of the Pentagon is %.2f\n", s);

    return 0;

}



double area(double x, double y, double z)

{

    double p = (x + y + z) / 2;

    return sqrt(p * (p - x) * (p - y) * (p - z));

}
函数的复用价值：把“求一个三角形面积”写好并验证一次，就能用不同实参组合 (a1,a5,a6)、(a4,a6,a7)、(a2,a3,a7) 连续调用三次！
23:00—25:00。引导学生观察第10行：函数调用本身就是一个表达式，可以直接参与加法运算。

深度追问：任意输入三个数都能算出面积吗？

潜在风险

如果输入的边长是 1, 2, 10，半周长 p = 6.5，则 p - z = -3.5，导致 sqrt 对负数开方，产生 NaN（非数值）！

几何合法性前提

三边均为正数，且满足任意两边之和大于第三边：

x > 0 && y > 0 && z > 0 && x + y > z && x + z > y && y + z > x

教材例5-3 题面描述

📋 题目要求

定义一个判断完全平方数的函数 isSquare(n)，当 \(n\) 为完全平方数时返回 1，否则返回 0。
（注：不允许调用数学库函数 sqrt）

不用 sqrt，怎样判断完全平方数？

思路A：枚举试乘

对于非负整数 \(n\)，让 \(i\) 从 \(0, 1, 2, \dots\) 递增，测试 \(i \times i\) 是否等于 \(n\)（当 \(i \times i > n\) 时停止）。

思路B：连续减奇数法（教材法）

利用数学性质：前 \(k\) 个连续正奇数之和等于 \(k^2\)：

\(1 + 3 + 5 + \dots + (2k-1) = k^2\)

把 \(n\) 依次减去 \(1, 3, 5, 7, \dots\)，如果最终恰好减到 0，说明它是完全平方数！
25:00—27:00。引导学生理解连续减奇数法：把 n 依次减去 1、3、5、7……如果正好减到 0，说明是完全平方数。

连续减奇数法：代码实现与过程跟踪

int isSquare(int n)

{

    int i;

    for (i = 1; n > 0; i = i + 2) {

        n = n - i;

    }

    if (n == 0)

        return 1;

    else

        return 0;

}
思考：循环里修改了形参 n，会影响 main 里的原变量吗？（不会，因为是值传递！）
初始 n 依次减去的奇数 i 循环结束时 n 返回值
9 9-1=8 → 8-3=5 → 5-5=0 0 1（是）
10 10-1=9 → 9-3=6 → 6-5=1 → 1-7=-6 -6 0（否）
0 n > 0 不成立，循环 0 次 0 1（\(0=0^2\)）
-4 n > 0 不成立，循环 0 次 -4 0（否）

判断型函数怎么在 main 中调用？

int isSquare(int n);



if (isSquare(n)) {

    printf("%d is a square number.\n", n);

} else {

    printf("%d is not a square number.\n", n);

}

🤖 AI 协作互动：两种无 sqrt 算法的对比与边界核验

判断非负整数 n 是否为完全平方数（不用 sqrt），方法一是 for(i=1; n>0; i+=2) n -= i; 判断 n==0；方法二是 for(i=0; i*i<n; i++); 判断 i*i==n。请对比这两种方法在 n=0、n=-1 以及 n 接近 int 最大值（如 2147483647）时的安全性差异，指出哪种写法可能发生整数乘法溢出。

出口题一：哪行函数首部合法？

A. double calcBMI(double weight, height)

B. double calcBMI(double weight, double height)

C. calcBMI(double weight, double height)

D. double calcBMI(double weight, double height);

结论：选 B

{

暴露问题的测试输入：(70.0, -1.75) 或 (-5.0, 1.75)
