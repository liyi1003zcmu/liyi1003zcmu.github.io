5.2 / 无返回值函数 void
有些函数负责“计算”，
有些函数负责“执行动作”
当函数的目标是向屏幕输出、改变硬件状态或执行控制流程，不需要带回数值时，用 void。
void printReport 独立语句调用 return; 提前退出

为什么需要无返回值函数？

数据计算：需要返回结果

calcBMI(70.0, 1.75) 计算后需要把 22.86 交代给主调程序，因此返回 double。

报告展示：执行输出动作

printReport(22.86) 的任务是向屏幕打印格式化慢病随访分析报告，并不产生一个需要继续参与运算的数字。

void printReport(double bmi)
{
    if (bmi <= 0) {
        printf("Error: invalid data\n");
        return;    /* Return early */
    }
    printf("Report: BMI = %.2f\n", bmi);
}
语法关键：void 表明该函数“不返回任何值”。末尾的 return; 不带表达式，用于立即跳出函数。
8:00—10:00。说明 void 函数的典型特征：依靠“副作用（如控制台打印）”产生作用。

两类函数，调用语法截然不同

有返回值的函数（double / int）

double b = calcBMI(70.0, 1.75);
if (isSquare(16)) ...
printf("%f", cylinder(2, 3));

✓ 必须或通常作为表达式的一部分出现，可参与赋值、算术或打印。

无返回值的函数（void）

printReport(b);   /* Valid call */

/* Common syntax errors: */
x = printReport(b);              /* Error! */
printf("%d", printReport(b));    /* Error! */

✗ 只能作为一条独立的语句执行，绝不能出现在需要数值的表达式中！

10:00—12:00。让学生预测：编译器对 x = printReport(r) 会给出什么报错提示（void value not ignored as it ought to be）。

有返回值函数 vs void 函数对比总结

对比维度 有返回值函数（double/int 等） 无返回值函数（void）
核心使命 计算或判断：向主调函数交付一个数据 执行操作：屏幕输出、格式化打印、状态修改
首部返回类型 具体数据类型，如 double、int 关键字 void
return 语句 必须写 return expr;，类型需匹配 可省略；若写只能是不带表达式的 return;
调用形式 变量接收 v = f(...) 或作为表达式因子 独立语句 f(...);

教材例5-6 题面描述

📋 题目要求

输入一个正整数 \(n\)（\(1 \le n \le 9\)），输出 \(n\) 行数字金字塔。
要求定义和调用函数 void pyramid(int n) 输出金字塔。

金字塔排版规律：空格与数字分解

以 \(n = 5\) 为例，仔细观察第 \(i\) 行（\(i = 1 \dots n\)）的字符构成：

行号 \(i\) 前置空格数（\(n - i\)） 打印内容（数字后带空格） 循环逻辑拆解
第 1 行 \(5 - 1 = 4\) 个空格 1 先循环打 4 个空格，再打 1 次 "1 "
第 2 行 \(5 - 2 = 3\) 个空格 2 2 先循环打 3 个空格，再打 2 次 "2 "
第 3 行 \(5 - 3 = 2\) 个空格 3 3 3 先循环打 2 个空格，再打 3 次 "3 "
第 \(i\) 行 \(n - i\) 个空格 \(i\) 次 "%d ", i 内层双循环：先输出空格，后输出数字

教材例5-6：函数实现与思考

#include <stdio.h>

void pyramid(int n);

int main(void)
{
    int n;
    scanf("%d", &n);
    pyramid(n);
    return 0;
}

void pyramid(int n)
{
    int i, j;
    for (i = 1; i <= n; i++) {
        for (j = 1; j <= n - i; j++)
            putchar(' ');
        for (j = 1; j <= i; j++)
            printf("%d ", i);
        putchar('\n');
    }
}

深度自问自答

  • 问：为什么定义成 void？
    因为该函数的核心任务是控制字符终端的光标与输出，没有计算出一个数值需要交还给 main。
  • 问：main 中能写 int res = pyramid(5); 吗？
    绝对不能！编译器会报错 void value not ignored。

边界异常分析

如果用户输入 \(n \le 0\)，循环不执行，控制台无任何反应；如果输入 \(n \ge 10\)，双位数宽度变为 2，金字塔斜边将严重错位歪斜！

契约式防护建议

在函数入口加入卫语句：

if (n < 1 || n > 9) {
    printf("Please enter an integer between 1 and 9\n");
    return;
}

教材例5-4 题面描述与算法流程

📋 教材例5-4 题目要求

输入两个正整数 \(m\) 和 \(n\)，定义并调用函数 gcd(m, n) 计算它们的最大公约数（Greatest Common Divisor）。

辗转相除法（欧几里得算法）：
用 \(m\) 除以 \(n\) 得余数 \(r\)；若 \(r = 0\)，则 \(n\) 即为最大公约数；否则令 \(m = n, n = r\)，继续求余。

辗转相除实现与致命除零漏洞

int gcd(int m, int n)
{
    int r;
    r = m % n;
    while (r != 0) {
        m = n;
        n = r;
        r = m % n;
    }
    return n;
}

🚨 致命漏洞检验

  • 若输入 gcd(18, 12)：返回 6（正常）。
  • 若输入 gcd(12, 18)：第一轮 \(12 \% 18 = 12\)，自动互换为 \(18 \% 12\)（正常）。
  • 若调用者传入 gcd(0, 0) 或 gcd(18, 0)：
    第 4 行 r = m % n; 将直接触发除以 0 致命崩溃（Floating Point Exception / SIGFPE）！
健壮性改造：函数入口必须先拦截非法值：if (n <= 0 || m <= 0) return -1;

教材例5-5：素数判断函数 prime(m)

📋 教材例5-5 题目要求

定义函数 int prime(int m)，当 \(m\) 是素数时返回 1，否则返回 0。

int prime(int m)
{
    int i;
    if (m <= 1) return 0;   /* Numbers <= 1 are not prime */
    for (i = 2; i <= m / 2; i++) {
        if (m % i == 0)
            return 0;        /* Found factor, return 0 early */
    }
    return 1;                /* Loop finished, is prime */
}

23:00—25:00。注意循环条件写成 i <= m / 2 或 i <= sqrt(m) 的性能考量；强调一旦整除立即 return 0，不浪费 CPU 算力。

参数安全再反思：格雷戈里公式 funpi(e)

函数的职责

负责迭代累加并由 fabs(item) >= e 控制精度收敛，向调用者返回 \(\pi\) 的近似值。

参数隐患：若传入 \(e \le 0\)？

若调用者传入 \(e = 0\)，浮点截断导致不可预知循环；若传入 \(e < 0\)，fabs(item) >= e 恒成立，直接引发死循环！

契约式设计（Design by Contract）：函数设计者绝不能假设“调用者一定会乖乖输入合法数据”！
