scanf("%d", &pulse);

while (pulse >= 0) {

    sum = sum + pulse;
    count++;
    scanf("%d", &pulse);
}

while 语句

while (表达式) {
    循环体语句;
}

执行顺序

  1. 先判断表达式是否为真
  2. 真：执行循环体
  3. 回到条件继续判断
  4. 假：跳出循环
重点：循环条件表示“继续循环”的条件，而不是“结束循环”的条件。

教材例4-1 题面描述

📋 题目要求

使用格雷戈里公式求 \(\pi\) 的近似值，要求精确到最后一项的绝对值小于给定精度 eps：

\[\frac{\pi}{4}=1-\frac{1}{3}+\frac{1}{5}-\frac{1}{7}+\ldots\]

教材例4-1：用格雷戈里公式求 π

\(\frac{\pi}{4}=1-\frac{1}{3}+\frac{1}{5}-\frac{1}{7}+\cdots\)

每一项

item 依次为 1, -1/3, 1/5, ...

变化规律

符号交替，分母每次加2。

停止规则

当 fabs(item) < eps 时停止。

从结束条件推出循环条件

题目要求的结束条件

fabs(item) < eps

当前项的绝对值已经小于给定精度。

继续循环的条件

fabs(item) >= eps

还没有达到停止要求，就继续累加。

循环条件通常是“结束条件”的逻辑否定。这里保留 = 是有依据的。

格雷戈里公式：代码骨架

flag = 1;
denominator = 1;
item = 1.0;
pi = 0;

while (fabs(item) >= eps) {
    pi = pi + item;
    flag = -flag;
    denominator = denominator + 2;
    item = flag * 1.0 / denominator;
}

pi = pi * 4;

重点然僧：每轮循环之后，item 必须向停止条件靠近。

跟踪变量：每轮循环改变了什么？

轮次 flag denominator item 动作
初始 1 1 1.0 准备第1项
第1轮后 -1 3 -1/3 准备下一项
第2轮后 1 5 1/5 准备下一项
第3轮后 -1 7 -1/7 准备下一项

循环体中最关键的不是“累加”，而是更新下一轮的状态。

扩展问题：这个 = 能不能去掉？

版本A

while (fabs(item) >= eps)

对应结束条件：fabs(item) < eps

版本B

while (fabs(item) > eps)

对应结束条件：fabs(item) <= eps

进一步追问：浮点数真的会精确等于我们写下来的十进制小数吗？

#include <stdio.h>

int main(void)
{
    double x = 0.1 + 0.2;

    printf("%.17f\n", x);
    printf("%.17f\n", 0.3);

    if (x == 0.3)
        printf("equal\n");
    else
        printf("not equal\n");
}

典型输出：数学值与机器表示并不总一致

可能看到的结果

0.30000000000000004
0.29999999999999999
not equal

课堂解释

  • 很多十进制小数无法用有限二进制精确表示
  • 计算机会保存一个足够接近的近似值
  • 浮点数做“相等判断”时要特别谨慎

整数与小数的表示差异

整数例子

13₁₀ = 1101₂

在一定范围内可以精确表示。

有限小数

0.5₁₀ = 0.1₂

可以有限表示。

循环小数

0.1₁₀ ≈ 0.000110011...

只能近似表示。

那为什么 fabs(item) >= eps 仍然合理？

阈值比较

fabs(item) >= eps

判断当前项是否还没有达到精度阈值。

相等比较

x == 0.3

判断两个浮点计算结果是否完全相等，通常要谨慎。

本例中的 eps 不是普通数字，而是“允许误差/精度阈值”。

从 for 到 while：问题变在哪里？

已知人数

for (i = 1; i <= n; i++) {
    scanf("%lf", &score);
    total += score;
}

未知人数

scanf("%lf", &score);
while (score >= 0) {
    total += score;
    scanf("%lf", &score);
}

统计平均成绩与不及格人数

设计问题 答案
重复操作 处理一个成绩：累计、计数、判断是否不及格
循环条件 score >= 0
结束标志 输入负数
需要维护的状态 total、num、fail

教材例4-2：修正后的代码框架

num = 0;
total = 0;
fail = 0;

scanf("%lf", &score);
while (score >= 0) {
    total += score;
    num++;
    if (score < 60)
        fail++;
    scanf("%lf", &score);
}

if (num > 0) {
    printf("Average: %.2f\n", total / num);
    printf("Number of failures: %d\n", fail);
}

注意：判断不及格用的是当前成绩 score，不是累计总分 total。
