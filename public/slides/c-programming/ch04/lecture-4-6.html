本课核心问题

如果答案不知道在哪里，程序怎样系统地寻找？

枚举

把可能的取值逐个尝试。

约束

只保留满足条件的组合。

优化

删除不必要的枚举，减少搜索范围。

枚举问题四步法

步骤 要回答的问题
1. 定义变量 有哪些未知量？
2. 确定范围 每个未知量可能取哪些值？
3. 写出约束 什么组合才是合法答案？
4. 输出结果 找到后是全部输出，还是只要最优/第一个？
循环负责“尝试”，条件语句负责“筛选”。

教材例4-11 题面描述

📋 题目要求

某工地需要搬运砖块，男人一人搬 3 块，女人一人搬 2 块，小孩两人搬 1 块。
如果想用 \(n\) 人正好搬 \(n\) 块砖，问有哪些搬法？

搬砖问题：先建模，不急着写代码

未知变量

  • men：男人数量
  • women：女人数量
  • children：小孩数量

两个约束

  • 人数：men + women + children == n
  • 砖数：3*men + 2*women + 0.5*children == n

为避免浮点比较，也可把砖数约束整体乘以2。

把约束改写为整数形式

原约束

3m + 2w + 0.5c == n

整体乘以2

6m + 4w + c == 2n

能用整数表达的约束，优先用整数表达，减少浮点比较带来的干扰。

版本1：直接枚举三个变量

cnt = 0;
for (men = 0; men <= n; men++) {
    for (women = 0; women <= n; women++) {
        for (children = 0; children <= n; children++) {
            if (men + women + children == n &&
                6 * men + 4 * women + children == 2 * n) {
                printf("men=%d, women=%d, children=%d\n", men, women, children);
                cnt++;
            }
        }
    }
}

这是最直接、最容易理解的枚举方式。

如果已经知道 men 和 women，还需要枚举 children 吗？

总人数是 n
→
已知 men
→
已知 women
→
children = n - men - women
不要枚举可以计算出来的变量。

版本2：删除可以计算出来的变量

men_limit = n / 3;
women_limit = n / 2;
for (men = 0; men <= men_limit; men++) {
    for (women = 0; women <= women_limit; women++) {
        children = n - men - women;
        if (children >= 0 &&
            6 * men + 4 * women + children == 2 * n) {
            printf("men=%d, women=%d, children=%d\n", men, women, children);
        }
    }
}
优化不是为了炫技，而是让程序少做不必要的尝试。

教材例4-12 题面描述

📋 题目要求

有足够数量的 5 分、2 分和 1 分硬币，现在要用这些硬币来支付一笔小于 1 元的零钱 money，问至少要用多少个硬币？
输入零钱 money，输出硬币的总数量和相应面额的硬币数量。

找零钱问题：变量、范围、目标

变量

n5、n2、n1 分别表示5分、2分、1分硬币数量。

约束

5*n5 + 2*n2 + n1 == money

目标

硬币总数尽量少，优先尝试面值大的硬币。

为什么从大面值开始枚举？

尽量多用5分
→
再尝试2分
→
最后补1分
→
先找到的通常更少
搜索顺序本身也表达了算法策略。

使用标志变量控制嵌套循环

flag = 1;
for (n5 = money / 5; n5 >= 0 && flag == 1; n5--) {
    for (n2 = (money - n5 * 5) / 2; n2 >= 0 && flag == 1; n2--) {
        for (n1 = money - n5 * 5 - n2 * 2; n1 >= 0 && flag == 1; n1--) {
            if (n5 * 5 + n2 * 2 + n1 == money) {
                printf("n5=%d, n2=%d, n1=%d, total=%d\n", n5, n2, n1, n5+n2+n1);
                flag = 0;
            }
        }
    }
}

这里的 flag 用于让多层循环都感知“已经找到答案”。

为什么只写一个 break 不够？

单层 break

只能跳出当前所在的一层循环。

flag 控制多层循环

每一层循环条件都检查 flag == 1，找到答案后统一停止。

当嵌套循环有多个出口时，标志变量可以把“是否继续搜索”传递给外层循环。
