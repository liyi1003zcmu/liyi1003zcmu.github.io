求最高分：
记录“到目前为止”的最大值
最值问题的关键，是让一个变量保存当前最优结果。
max状态保持比较更新

教材例4-8 题面描述

📋 题目要求

输入一批学生的成绩，找出最高分。
（注：当输入负数时标志数据输入结束）

从脉搏记录看“当前最大值”

7268757169
读入当前值
→
与 max 比较
→
更大则更新
→
继续下一条

医学情境只用于理解变量更新；教材例题仍以学生成绩为主进行训练。

求一批成绩中的最高分

scanf("%d", &mark);
max = mark;          /* 假设第一个成绩是最高分 */

while (mark >= 0) {
    if (mark > max)
        max = mark;
    scanf("%d", &mark);
}
求最值的核心：先让 max 有一个合理初值，再不断用新数据挑战它。

跟踪 max：它什么时候变化？

输入成绩 比较前 max 是否更新 比较后 max
82 - 初始化 82
76 82 否 82
91 82 是 91
88 91 否 91
-1 91 结束标志 91

求最值常见错误：初值随便给

可能出错

max = 0;
while (...) {
    ...
}

如果数据范围不是0以上，就可能出错。

更稳妥

scanf("%d", &mark);
max = mark;

用第一个有效数据初始化最大值。

初值不是形式问题，而是算法正确性的起点。

Fibonacci数列：
新状态由旧状态产生
循环中最重要的变量，常常不是输入，而是“上一轮留下来的状态”。
x1x2状态迭代

教材例4-9 题面描述

📋 题目要求

输入正整数 \(n\) (\(1 \le n \le 46\))，输出斐波那契（Fibonacci）数列的前 \(n\) 项：\(1, 1, 2, 3, 5, 8, 13, \ldots\)，每行输出 5 个。
（注：Fibonacci 数列满足任一项数字是前两项的和，最开始的两项均定义为 1）

Fibonacci数列规则

1, 1, 2, 3, 5, 8, 13, ...

前两项

x1 = 1, x2 = 1

新项

x = x1 + x2

状态移动

x1 = x2;
x2 = x;

状态如何向前移动？

轮次 x1 x2 x=x1+x2 更新后
开始 1 1 2 x1=1, x2=2
下一轮 1 2 3 x1=2, x2=3
再下一轮 2 3 5 x1=3, x2=5
本题的循环体不是简单输出，而是不断更新“前两项”的状态。

输出Fibonacci数列前 n 项

x1 = 1;
x2 = 1;
printf("%10d%10d", x1, x2);
for (i = 3; i <= n; i++) {
    x = x1 + x2;
    printf("%10d", x);
    x1 = x2;
    x2 = x;
}

先输出前两项，再循环产生后面的 n-2 项。

每行输出5个：循环中的格式控制

printf("%10d", x);
if (i % 5 == 0)
    printf("\n");

计算任务

产生数列的下一项。

显示任务

每输出5项后换行，便于阅读。

循环体中可以同时包含“计算”和“输出控制”。

教材例4-10 题面描述

📋 题目要求

输入 2 个正整数 \(m\) 和 \(n\) (\(1 \le m \le n \le 500\))，输出 \(m\) 到 \(n\) 之间的全部素数，每行输出 10 个。
（注：素数指的是只能被 1 和自身整除的正整数，1 不是素数，2 是素数）

从“一个素数”到“一批素数”

枚举 k=m...n
→
判断 k 是否为素数
→
若是则输出
→
控制每行数量

外层

候选数 k 从 m 到 n。

内层

对当前 k 尝试寻找因子。

复用上一课：判断 k 是否为素数

flag = 1;
limit = sqrt(k) + 1;
for (i = 2; i <= limit; i++) {
    if (k % i == 0) {
        flag = 0;
        break;
    }
}
if (flag == 1)
    printf("%d ", k);
这里的 break 表示：只要找到一个因子，就不需要继续检查。

输出 m 到 n 之间的全部素数

count = 0;
for (k = m; k <= n; k++) {
    flag = 1;
    limit = sqrt(k) + 1;
    for (i = 2; i <= limit; i++) {
        if (k % i == 0) {
            flag = 0;
            break;
        }
    }
    if (flag == 1) {
        printf("%5d", k);
        count++;
        if (count % 10 == 0) printf("\n");
    }
}

代码诊断：区间素数中最容易错在哪里？

边界

1 不是素数，2 是素数。

flag重置

每判断一个新的 k，都要重新设置 flag。

循环条件

i <= limit 与 i < limit 要保持逻辑一致。

组合程序最容易出错的地方，往往不是语法，而是“每一轮是否重新初始化状态”。
