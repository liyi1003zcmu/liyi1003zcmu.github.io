循环不变操作 · 每一轮都在做什么？ 4步循环体原型
① 取当前个位
digit = number % 10;
剥离最末尾数字供处理
② 处理这一位
count++; 或 printf("%d", digit);
统计位数或输出当前数字
③ 剔除当前个位

整数截断，数字向右收缩
④ 判定剩余数字

不为 0 继续，归 0 退出
核心认知：每轮操作完全相同，但 number 的数值逐步递减，驱动循环迈向终点。
为什么输入 0 时 do-while 特别自然？ 核心考点
数学上 0 是一位整数。若采用普通 while (number != 0)，输入为 0 时条件一开始就为假，循环体一次都不执行，得到错误结果 0 位。
do-while 保证循环体至少执行一次：先进入循环体处理个位 0（count 增加为 1），再判断 0 != 0 为假而优雅终止！
普通 while 语句:
while (number != 0) { ... }
输入 0: 执行 0 次 ➔ 统计为 0 位 (错误)
do-while 语句:
do { ... } while (number != 0);
输入 0: 至少执行 1 次 ➔ 统计为 1 位 (正确)
1 % 10 负责“取个位”
通过模 10 运算精准剥离整数最末尾的个位数字，例如 495 % 10 = 5。
2 / 10 负责“删个位”
C语言整数除法自动截断小数部分，实现彻底移除当前个位：495 / 10 = 49。
3 状态单向收缩收敛
状态演进序列：495 → 49 → 4 → 0，数值步步缩减直至触发终止条件 number == 0。
4 同一个算法骨架
无论统计位数 (count++) 还是逆序打印 (printf)，核心骨架均为重复的 %10 与 /10。
教学箴言：找到“每轮重复的操作”和“不断收敛的状态”，就是在设计循环！
