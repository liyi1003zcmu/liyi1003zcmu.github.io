边界观察：当 fabs(item) 接近或到达 eps 时，>= 相比 > 会多执行一次累加。 机器比较的是真实浮点存储近似值

1 边界由问题定义
循环终止条件若为 fabs(item) < eps，则其逻辑对立的继续条件即为 fabs(item) >= eps。
2 整数与小数不同
整数由有限个 2ᵏ 权值构成，能被精确表示；而 0.1 等小数转化为二进制是无限循环小数，只能近似存储。
3 浮点判等须谨慎
绝不能把数学上的“相等”与机器浮点数的 == 画等号。0.1 + 0.2 在机器中与 0.3 存在微小舍入差值。
4 eps 是允许误差
数值计算不苛求“完全数学相等”，而是通过精度阈值 eps 控制逼近程度，判断余项绝对值是否已足够微小。
教学箴言：先定义数学边界，再设计程序条件，最后考虑机器表示。 （本演示用于理解浮点表示与循环精度的基本思想，不展开 IEEE 754 细节）
