先执行，再判断。

do-while 语句

do {
    循环体语句;
} while (表达式);

执行顺序

  1. 先执行循环体
  2. 再判断表达式
  3. 真：继续下一轮
  4. 假：结束循环
注意：do-while 结尾有分号。

while 与 do-while 的核心差别

结构 判断位置 循环体最少执行次数 适合问题
while 循环前 0次 条件进入前已明确
do-while 循环后 1次 必须先执行一次才能判断

教材例4-3 题面描述

📋 题目要求

从键盘读入一个整数，统计该数的位数。

以 495 为例：从低位向高位处理

495→49→4→0
当前number number % 10 number / 10 位数
495 5 49 1
49 9 4 2
4 4 0 3

逐位处理的循环模式

取出当前个位

digit = number % 10;

用于得到当前最右边一位。

去掉当前个位

number = number / 10;

整数除法会舍去小数部分。

每循环一次，处理一位数字，同时让 number 更接近0。

用 do-while 统计整数位数

count = 0;

do {
    number = number / 10;
    count++;
} while (number != 0);

即使输入为 0，循环体也会执行一次，因此结果为1位。

为什么输入 0 时更适合 do-while？

while版本

count = 0;
while (number != 0) {
    number = number / 10;
    count++;
}

当 number=0 时，循环一次也不执行。

do-while版本

count = 0;
do {
    number = number / 10;
    count++;
} while (number != 0);

当 number=0 时，也能得到1位。

统计整数位数：完整程序框架

#include <stdio.h>

int main(void)
{
    int count, number, t_number;

    printf("Enter a number: ");
    scanf("%d", &number);
    t_number = number;

    if (t_number < 0)
        t_number = -t_number;

    count = 0;
    do {
        t_number = t_number / 10;
        count++;
    } while (t_number != 0);

    printf("It contains %d digits.\n", count);
    return 0;
}

整数逆序输出：代码框架

do {
    printf("%d ", number % 10);
    number = number / 10;
} while (number != 0);

循环体

输出当前个位，并去掉当前个位。

循环条件

只要还有剩余数字，就继续处理。

统计位数与逆序输出：共同结构

任务 每轮处理 每轮更新 结束条件
统计位数 count++ number = number / 10 number == 0
逆序输出 printf(number % 10) number = number / 10 number == 0
同一循环骨架可以服务不同任务，关键在于循环体中“处理当前状态”的方式。
