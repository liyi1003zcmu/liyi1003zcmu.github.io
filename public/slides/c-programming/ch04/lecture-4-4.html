阶乘函数嵌套循环

教材例4-7 题面描述

📋 题目要求

输入一个正整数 \(n\) (\(n \le 16\))，计算 \(1!+2!+3!+\ldots+n!\)。
要求定义和调用函数 fact(n) 计算 \(n\) 的阶乘，如果 \(n\) 是非负数，则该函数返回 \(n\) 的阶乘，否则返回 0。

先看一个小任务：求 n!

double fact(int n)
{
    int i;
    double result = 1;
    for (i = 1; i <= n; i++)
        result = result * i;
    return result;
}
这一层循环解决的是：从 1 乘到 n。

再看大任务：求 1!+2!+...+n!

sum = 0;
for (i = 1; i <= n; i++)
    sum = sum + fact(i);

外层循环

i = 1, 2, ..., n，依次求每个阶乘。

函数内部循环

fact(i) 内部再完成从1乘到i。

把函数内部展开，就是嵌套循环

sum = 0;
for (i = 1; i <= n; i++) {
    item = 1;
    for (j = 1; j <= i; j++) {
        item = item * j;
    }
    sum = sum + item;
}

外层负责“求第几个阶乘”，内层负责“把这个阶乘算出来”。

item = 1 应该放在哪里？

正确位置

for (i = 1; i <= n; i++) {
    item = 1;
    for (j = 1; j <= i; j++)
        item = item * j;
    sum = sum + item;
}

常见错误

item = 1;
for (i = 1; i <= n; i++) {
    for (j = 1; j <= i; j++)
        item = item * j;
    sum = sum + item;
}

为什么每次外层循环都要重新置 item=1？

求 1!

从1开始乘。

求 2!

仍然要从1重新开始乘。

求 3!

不能沿用上一次残留的 item。

内层循环使用的临时变量，往往需要在每次外层循环开始时重新初始化。
