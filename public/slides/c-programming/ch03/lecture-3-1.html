本页沿用第二次课的脉搏示例规则，重点是“区间→条件”的转换。

else if：前面不成立，才继续判断

if (条件1) {
    语句1;
} else if (条件2) {
    语句2;
} else {
    语句3;
}

执行逻辑

  1. 先判断条件1。
  2. 不成立，才判断条件2。
  3. 前面都不成立，执行 else。
  4. 一旦某个分支执行，后面分支跳过。

把三个区间写成一个多分支

int p;
scanf("%d", &p);

if (p < 60) {
    printf("Slow pulse\n");
} else if (p <= 100) {
    printf("Suitable\n");
} else {
    printf("Fast pulse\n");
}

为什么第二个条件只写 p <= 100？

因为走到这里已经意味着 p >= 60。

条件写对了，顺序也可能写错

    printf("Fast\n");
版本B：先写更宽条件

同样是多分支，只是条件换成了字符

if (op == '+')
    计算 value1 + value2;
else if (op == '-')
    计算 value1 - value2;
else if (op == '*')
    计算 value1 * value2;
else if (op == '/')
    计算 value1 / value2;
else
    提示 Unknown operator;

连续区间 → 比较数值；固定运算符 → 比较字符。

完整的 if-else if 版本

double value1, value2;
char op;

scanf("%lf %c %lf", &value1, &op, &value2);

if (op == '+') {
    printf("= %.2f\n", value1 + value2);
} else if (op == '-') {
    printf("= %.2f\n", value1 - value2);
} else if (op == '*') {
    printf("= %.2f\n", value1 * value2);
} else if (op == '/') {
    if (value2 != 0)
        printf("= %.2f\n", value1 / value2);
    else
        printf("Divisor cannot be 0!\n");
} else {
    printf("Unknown operator!\n");
}

为什么除法分支里还要再判断一次？

第一层

op == '/'

用户选择了除法。

第二层

value2 != 0

除法还有自己的前提条件。

这就是“分支内部继续分支”的最小例子。

现在你能解释这两种“多分支”了吗？

脉搏区间

p < 60 / p <= 100 / 其它

条件来自连续数值区间。

运算符

op == '+' / '-' / '*' / '/'

条件来自若干固定字符。

第1课时小结

  • 多分支：else if 按顺序检查多个条件。
  • 隐含范围：前一条件失败，会缩小后一条件的有效范围。
  • 边界测试：优先检查59/60、100/101一类边界。
  • 字符数据：char 可保存运算符等单字符信息。
  • 混合输入：%lf %c %lf 读取不同类型数据。
  • 嵌套判断：一个分支内部可以继续判断自己的特殊条件。
