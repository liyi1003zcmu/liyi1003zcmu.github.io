3.1 / switch-case
一个变量对应多个固定值：
用 switch 表达更直接

switch 先看表达式的值，再找匹配的 case

switch (表达式) {
    case 常量1:

    case 常量2:
        语句段2;
        break;

        默认语句段;
        break;
}

3.2 / break 与贯穿执行
为什么每个 case
后面通常都要有 break？
预测运行解释

如果删掉 break，输入 1 会输出什么？

switch (choice) {
    case 1:
        printf("Record pulse\n");
    case 2:
        printf("Show range hint\n");
    case 3:
        printf("Compare readings\n");
    default:
        printf("End\n");
}
只输出1行？
输出2行？
一直向后执行？
课堂投票30秒；再运行验证。重点不是记“break必须写”，而是理解case只负责找到入口。

没有 break：会继续向后执行

输入1

  1. 找到 case 1
  2. 执行case 1
  3. 继续执行case 2
  4. 继续执行case 3
  5. 继续执行default

因此

break;

不是“结束程序”，而是离开当前 switch。

这也是为什么删除一个 break 会改变后续所有输出。

用户输入 9 怎么办？

default:
    printf("Invalid choice\n");
    break;
设计意识：菜单不仅要说明“正确选项做什么”，还要定义“其他输入怎么办”。
3.3 / 迁移与结构选择
同一个问题，
什么时候用 if，什么时候用 switch？
范围固定值可读性

运算符也是“一个变量 + 多个固定值”

switch (op) {
    case '+':
        printf("= %.2f\n", value1 + value2);
        break;
    case '-':
        printf("= %.2f\n", value1 - value2);
        break;
    case '*':
        printf("= %.2f\n", value1 * value2);
        break;
    case '/':
        if (value2 != 0)
            printf("= %.2f\n", value1 / value2);
        else
            printf("Divisor cannot be 0!\n");
        break;
    default:
        printf("Unknown operator!\n");
}

同一个程序里可以同时存在 switch 和嵌套的 if。

if-else 与 switch 各自擅长什么？

问题 更自然的结构 原因
p < 60 if 范围比较
60 <= p && p <= 100 if 复合条件
choice = 1/2/3/4 switch 固定离散选项
op = '+'/'-'/'*'/'/' switch 固定字符值

脉搏数据助手的两层选择

第1层：选功能

switch (choice) {
    case 2:
        // 查看状态提示
        ...
}

固定菜单值 → switch

第2层：做区间判断

if (p < 60)
    ...
else if (p <= 100)
    ...
else
    ...

连续范围 → if-else

程序结构不是“二选一”，而是根据问题把不同结构组合起来。

先搭结构，再逐步填充功能

#include <stdio.h>

int main(void)
{
    int choice, p;
    scanf("%d", &choice);

    switch (choice) {
        case 1:
            scanf("%d", &p);
            break;
        case 2:
            scanf("%d", &p);
            if (p < 60)
                printf("Slow pulse\n");
            else if (p <= 100)
                printf("Suitable\n");
            else
                printf("Fast pulse\n");
            break;
        default:
            printf("Invalid choice\n");
    }
    return 0;
}

这里只展示结构骨架；循环菜单将在后续循环结构中继续升级。

第2课时小结

  • switch：适合“同一个变量匹配多个固定值”。
  • case：提供可能的入口，不会自动结束。
  • break：结束当前分支并离开 switch。
  • default：处理没有匹配任何 case 的情况。
  • 结构选择：范围/复杂条件优先 if，固定离散值优先 switch。
  • 组合：菜单用 switch，菜单内部仍可继续使用 if。
