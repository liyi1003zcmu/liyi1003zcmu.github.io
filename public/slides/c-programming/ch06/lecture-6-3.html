什么是表达式？C 语言表达式的本质与特征

1. 表达式的定义与两大核心属性

定义：表达式（Expression）是由操作数（常量、变量、函数返回值等）与运算符按 C 语言语法规则组合而成的计算式。
核心属性 ① 确定值与类型：任何表达式求值后，必定产生一个唯一的数值结果与确定的数据类型。
核心属性 ② 潜在副作用：部分表达式（如赋值、自增自减）在产生值的同时，还会改变变量在内存中的状态。

2. 表达式（Expression） vs 语句（Statement）

纯表达式：a + b、x = 10、count++（可作为子表达式嵌入他处）。
表达式语句：在表达式末尾加上分号 ;，即构成一条独立的语句： 

x = 10;          /* 赋值表达式语句 */
count++;         /* 自增表达式语句 */
printf("Hello"); /* 函数调用表达式语句 */

单独写 a + b; 语法合法，但由于没有副作用，计算结果被直接丢弃。

学习提示：C 语言是典型的“表达式驱动语言”。理解每一个表达式的类型、求值结果以及是否产生副作用，是编写高质量代码的基础。

数据计算与赋值类表达式详解及代码示例

1. 算术与自增自减表达式

int a = 14, b = 4;
int div1 = a / b;           /* 整数除法：3 (向零截断) */
double div2 = (double)a / b; /* 浮点除法：3.5 */
int mod = a % b;            /* 取模运算：2 (两端必须为整型) */

int i = 5, v1, v2;
v1 = i++;                   /* 后置自增：先取值 v1=5，后 i 变为 6 */
v2 = ++i;                   /* 前置自增：先自增 i 变为 7，后取值 v2=7 */

辨析要点：/ 根据操作数类型决定是整数除法还是浮点除法；取模 % 要求操作数必须为整数；前置与后置决定了表达式本身取自增前还是自增后的值。

2. 简单赋值、复合赋值与辅助表达式

int x, y, z;
x = y = z = 20;             /* 连续赋值：从右至左求值，整体值为 20 */
x += 5;                     /* 复合赋值：等价于 x = x + 5 */

int val;
if ((val = check()) > 0)    /* 赋值本身也是表达式，具备值和副作用 */

size_t sz = sizeof(double); /* sizeof 表达式：返回类型字节大小 8 */

辨析要点：在 C 语言中，赋值是表达式而非独立语句，其求值结果是被赋的值，并产生修改变量的副作用；sizeof 是编译期计算运算符。

执行特征：这类表达式聚焦于数值的加工与变量状态的更新，由 CPU 算术逻辑单元（ALU）完成计算并写回内存。

判断、控制与特殊类表达式详解及代码示例

1. 关系、逻辑与条件表达式

int sbp = 150, dbp = 95;
/* 关系表达式：比较运算，结果为 1 (真) 或 0 (假) */
int is_high_sbp = (sbp >= 140);  /* 结果: 1 */

/* 逻辑表达式：&& (与), || (或), ! (非)，具短路保护 */
int is_danger = (sbp >= 140) || (dbp >= 90); /* 结果: 1 */

/* 条件表达式 (三目运算)：二选一内联求值 */
char level = (sbp >= 140) ? 'H' : 'N';       /* 结果: 'H' */

辨析要点：关系与逻辑表达式返回值均为整型 1 或 0；逻辑运算符具备遇到左侧定局即跳过右侧的短路求值特性；三目运算符适合精简二选一赋值。

2. 位运算、逗号与函数调用表达式

unsigned char flag = 0x01;
flag |= 0x02;               /* 按位或：开启第 1 位标记 (置 1) */
int is_set = flag & 0x01;   /* 按位与：检测第 0 位是否有效 */

/* 逗号表达式：从左到右依次求值，取最末项的值 */
int i, j;
for (i = 0, j = 10; i < j; i++, j--) { ... }

/* 函数调用表达式：执行函数并接收其返回值 */
double dist = sqrt(16.0);   /* 表达式的值为 4.0 */

辨析要点：位运算直接操作整型变量的底层二进制比特位；逗号表达式优先级最低，常用于循环头部同时迭代多个变量；函数调用表达式以其返回值参与外层计算。

执行特征：这类表达式聚焦于程序的分支选择、逻辑流转与位级状态管理，是编写高质量防御性与系统级代码的利器。
6.3 / 逻辑运算与短路机制
连接条件的逻辑网络：
短路求值的双刃剑
逻辑运算符不仅仅是条件的拼接，短路保护是编写防御性代码的核心利器。
连续比较陷阱 && || ! 短路求值 防除零保护

一个看似正确的区间判断：剖析连续比较陷阱

int sbp = 220;   /* 严重高血压收缩压 */

if (60 <= sbp <= 140) {
    printf("血压处于正常范围！\n");   /* 此分支会被执行，与预期逻辑不符 */
}

微观运行步骤推演（左结合）

  1. <= 属于左结合运算符：先算 (60 <= sbp)
  2. 60 <= 220 为真，得到整型逻辑值 1
  3. 原式等价于：1 <= 140
  4. 1 <= 140 恒为真！无论 sbp 是 220 还是 500，条件永远成立！

C 语言规范写法

sbp >= 60 && sbp <= 140

必须将两个独立的二元关系表达式，通过逻辑与 && 显式连结在一起！两边同时成立才算正常。

逻辑与、或、非：真值表与组合规则

逻辑运算符 语法形式 真值判定规则 医学随访判定示例
逻辑与 && A && B 当且仅当 A 与 B 均非零时为真（1），否则为 0 sbp >= 90 && sbp <= 139（血压正常需两端达标）
逻辑或 || A || B 只要 A 或 B 中至少一个非零即为真（1），全零为 0 sbp >= 140 || dbp >= 90（收缩压或舒张压任一超标即高血压）
逻辑非 ! !A 单目运算：若 A 为零则为 1；若 A 非零则为 0 !isValid（数据不合规时报警）

短路求值：右边有可能根本不执行！

逻辑与短路（A && B）

如果左侧表达式 A 的值为假（0），则整个逻辑与的结果注定为假。C 语言规定：右侧表达式 B 被立即跳过，绝不执行！

逻辑或短路（A || B）

如果左侧表达式 A 的值为真（非0），则整个逻辑或的结果注定为真。C 语言规定：右侧表达式 B 同样被立即跳过，绝不执行！

警惕副作用：如果右侧表达式包含 count++ 或函数调用，当短路发生时，这些副作用完全不会发生！切勿在右侧放置依赖执行的赋值代码。

交互演示：观察右侧是否被跳过

💡 动手实验：点击预设按钮，观察当 count = 0 时，右侧除法 (sum / count) >= 140 是否直接跳过，从而避免了除以 0 引发运行异常。

短路特性的经典实战：防除零卫语句

int count = 0, sum = 240;

/* 安全优雅的防崩单行判定：*/
if (count != 0 && (sum / count) > 140) {
    printf("平均收缩压超标，触发慢病随访预警！\n");
}

/* 若 count 为 0，左边 count != 0 为假，右边除法根本不会被触发！*/
利用 && 短路特性保护右侧危险操作（如除零、数组越界、空指针解引用），是 C 语言防御性编程的核心技巧。

条件表达式：适合简单的二选一

常规 if-else 写法（略显繁琐）

char level;
if (sbp >= 140) {
    level = 'H';   /* High: 偏高 */
} else {
    level = 'N';   /* Normal: 正常 */
}

条件运算符 ? : 写法（精炼内联）

char level = (sbp >= 140) ? 'H' : 'N';

语法规则：表达式1 ? 表达式2 : 表达式3
先判断表达式1，为真取表达式2，为假取表达式3。

规范建议：条件表达式适合用于简洁的赋值或直接作为 printf 参数；切忌嵌套超过两层，否则严重破坏代码可读性。

复合赋值和逗号表达式在循环中的位置

逗号运算符 ,

表达式1, 表达式2, ..., 表达式n

从左到右依次执行求值，整个逗号表达式的值是最后一个子表达式的值。其优先级在全 C 语言中最低。

典型应用：多变量控制循环

for (i = 0, j = 10; i < j; i++, j--) {
    /* 头部逗号用于在一行内初始化或迭代多个变量 */
}

仅建议在 for 循环头部等紧凑场景使用，其他地方滥用容易制造晦涩陷阱。

逻辑运算与位运算，符号很像

类别 运算符 运算对象 求值特性 返回值
逻辑运算符 &&, ||, ! 真假条件（0 或 非0） 具备短路特性 只能是 0 或 1

字符运算：大写字母如何变成小写？

ASCII 码间距差值法则

'a' - 'A' = 97 - 65 = 32

大写与小写字母相隔固定值 32（0x20）。加上 32 转小写，减去 32 转大写！利用位运算也可以用 ch | 0x20 瞬间转小写。

字符转数字真值

'5' - '0' = 53 - 48 = 5

减去基准字符 '0'，就能立刻把 ASCII 数字字符转化为可直接参与四则运算的真实整数！

保留教材例题：逐个字符改变大小写

#include <stdio.h>

int main(void) {
    char ch;
    while ((ch = getchar()) != '\n' && ch != EOF) {
        if (ch >= 'A' && ch <= 'Z') {
            ch = ch + 32;       /* 大写转小写 */
        } else if (ch >= 'a' && ch <= 'z') {
            ch = ch - 32;       /* 小写转大写 */
        }
        putchar(ch);
    }
    putchar('\n');
    return 0;
}
利用 getchar() 配合循环条件里的赋值表达式，是 C 语言流式读取字符的经典模式。

单词统计：为什么不能只数空格？

幼稚做法：简单数空格数

认为“单词数 = 空格数 + 1”：

/* 遇到输入 "  AI   assists C  "：*/
/* 统计出 8 个空格，误判为 9 个单词！*/

主要缺陷：当存在连续空格、行首空格或行尾空格时，空格计数无法对应实际单词数。

状态机思维：看的是“边界跳变”

真正决定一个新单词出现的，不是空格本身，而是从“非单词字符（空格）”跨入“单词字符”的那一瞬间跃迁！

用状态变化替代繁琐条件

前一字符是空格
in_word = 0
→ 读到非空格字符 →
进入新单词！
count++，in_word = 1

状态定义

声明一个标志变量 int in_word = 0;：
0 表示当前处于单词之外（空格区域）；
1 表示当前正位于单词内部。

状态转移判定

if (ch == ' ') {
    in_word = 0;
} else if (in_word == 0) {
    in_word = 1;
    wordCount++;
}

逐字符演示：单词计数状态机

💡 观察重点：点击“前进一步”，观察 in_word 状态指示器在穿梭于连续多空格与字母之间时是如何平稳切换的，行首空格和连续空格不再造成误判！

单词计数核心代码与循环状态维护

int ch, count = 0;
int in_word = 0;   /* 0: 处于空格状态; 1: 处于单词内部 */

while ((ch = getchar()) != '\n' && ch != EOF) {
    if (ch == ' ') {
        in_word = 0;   /* 离开单词，进入空格状态 */
    } else if (in_word == 0) {
        /* 从空格状态第一次跃迁进入字母：发现新单词！*/
        in_word = 1;
        count++;
    }
}

printf("总单词数: %d\n", count);
这正是计算机科学中最核心的基石模型之一——有限状态自动机（FSM）的极简实现。

  • 超量程数据（如录入失误 280 或负数）视为异常脏数据，予以剔除并警示

系统目标

统计有效记录总数、异常数据个数，并在完全规避除零风险的前提下，计算出合规记录的平均收缩压，评定高血压风险等级。

模块化分解：设计单一职责的指标判断函数

/* 判断单次收缩压读数是否在合理医学量程范围内 (30~240 mmHg) */
int isValidSBP(int sbp) {
    return (sbp >= 30 && sbp <= 240);
}

/* 判断是否属于高血压警戒线 (>= 140 mmHg) */
int isHypertension(int sbp) {
    return (sbp >= 140);
}
将具体的区间判断公式从主业务循环中抽离成独立谓词函数，极大提升逻辑表达力与可测性。

主程序片段：循环中的多重逻辑与短路过滤

int sbp, sum = 0, validCount = 0, invalidCount = 0;

/* 利用 scanf 状态与非哨兵值双重条件控制循环 */
while (scanf("%d", &sbp) == 1 && sbp != -1) {
    if (isValidSBP(sbp)) {
        sum += sbp;
        validCount++;
    } else {
        invalidCount++;
        printf("【警告】检测到超量程异常数据: %d mmHg，已自动剔除！\n", sbp);
    }
}

健壮输出：短路防除零与综合报表

printf("\n=== 慢病随访质量分析报告 ===\n");
printf("有效随访条数: %d 条 | 异常剔除条数: %d 条\n", validCount, invalidCount);

/* 利用短路安全与条件表达式生成评估：*/
if (validCount > 0) {
    double avg = (double)sum / validCount;
    printf("合规随访平均收缩压: %.2f mmHg (评级: %s)\n",
           avg, (avg >= 140.0) ? "高血压预警" : "正常随访");
} else {
    printf("未采集到任何合规记录，无法计算平均值。\n");
}

第3课时总结：从表达式走向程序质量

1. 逻辑与短路

  • 禁止 a <= x <= b 连续比较
  • 必须用 && 显式拼接条件
  • 利用短路特性优雅实现防除零卫语句
  • 警惕短路时跳过右侧自增副作用

2. 运算符与位掩码

  • 条件表达式 ? : 保持简单清晰
  • 分清逻辑运算 && 与位运算 &
  • 位掩码用单个整数高效记录多种状态
  • 利用 &, |, ~ 灵活按位检测与开关

3. 状态机模型

  • 字符本质也是 ASCII 整数
  • 字符与数字互转：'5'-'0'=5
  • 用状态变量 in_word 解决空格跳变
  • 状态机模型是解决流式处理的利器

Exit Ticket · 综合检验

【综合诊断题】
① 若 int sbp = 160;，表达式 60 <= sbp <= 140 的最终计算值是 0 还是 1？为什么？
② 在 int count = 0; if (count != 0 && (100 / count > 5)) 中，除法是否会被执行？为什么？
③ 假设 status 的第 1 位代表高血压标记，如何用一行 C 语言位运算语句将其开启置 1？

① 答案：1（为真）。 左结合先算 60 <= 160 得到 1；再算 1 <= 140 恒为 1！正确写法必须为 sbp >= 60 && sbp <= 140。

② 答案：不会执行。 触发逻辑与 && 短路求值。左侧 count != 0 判定为假，右侧除法表达式被立即跳过，避免了除以 0 引发异常。

③ 答案：status |= (1 << 1);。 利用按位或 | 与左移掩码，将目标位置 1，其余位保持不变。
