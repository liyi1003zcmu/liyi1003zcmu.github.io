6.2 / 除法机制与强制转换
整数除法与浮点除法：
类型与转换位置的影响
C 语言除法符号 / 的含义取决于操作数类型，强制类型转换需要作用于正确的操作数。
整数除法 / 向零截断 强制类型转换 括号与优先级

数据场景：慢病随访收缩压均值计算的精度丢失

int totalSys = 385;   /* 3 次随访收缩压总和 (mmHg) */
int count = 3;        /* 随访测量次数 */

double avgSys = totalSys / count;   /* 期望得到 128.33 */

printf("平均收缩压: %.2f mmHg\n", avgSys);

实际运行输出

平均收缩压: 128.00 mmHg

计算结果显示为 128.00 mmHg。为什么将结果赋给 double 类型的 avgSys，依然没有保留小数？

计算过程分析

totalSys / count 是两个整型变量相除。C 语言在执行除法运算时，会先进行整数除法，向零截断得到整数 128，然后再赋值给 avgSys，因此最终为 128.0。

互动实验：除法的类型究竟在哪里决定？

💡 观察重点：修改累计和与次数，观察 sum / count（未转换）与 (double)sum / count（显式转换）的实时计算对比。特别注意：当 count = 0 时需提前判断，避免除以 0。

机制剖析：整数除法 vs 浮点除法对比表

表达式 操作数类型 运算行为 最终计算结果 原理说明
5 / 2 int ÷ int 整数除法 2 向零截断：小数部分直接被舍弃
-5 / 2 int ÷ int 整数除法 -2 向零靠拢（非向下取整，不是 -3）
5.0 / 2 double ÷ int 浮点除法 2.5 2 自动提升为 2.0，执行浮点除法
(double)5 / 2 double ÷ int 浮点除法 2.5 强制类型转换运算符 (double) 优先于除法
基本规则：除法运算符 / 的两个操作数中，只要有至少一个是浮点型，整场运算即作为浮点除法进行。

强制类型转换：(double) 放置位置对结果的影响

不恰当写法：括号包住整个表达式

(double)(totalSys / count)

  1. 圆括号拥有最高优先级，先计算 totalSys / count
  2. 两个 int 相除先得到截断后的整数 128，原有小数已不复存在
  3. 再强制转换为 double，得到的值只能是 128.00

正确写法：转换符优先作用于操作数

(double)totalSys / count

  1. 单目转换符 (double) 优先级高于双目除法 /
  2. 先将 totalSys 的值提升为浮点数 385.0
  3. 385.0 / 3 触发浮点除法，得到 128.333...

在慢病随访函数中封装健壮的均值计算

double calcAverageSys(int totalSys, int count)
{
    /* 检查除数有效性，避免除以 0 */
    if (count <= 0) {
        return -1.0;
    }
    return (double)totalSys / count;   /* 正确触发浮点除法 */
}

int main(void)
{
    double avg = calcAverageSys(385, 3);
    printf("慢病居民平均收缩压: %.2f mmHg\n", avg);   /* 输出 128.33 */
    return 0;
}
检查除数合法性并显式转换操作数类型，是编写数值计算函数的基本规范。

规则 1：整数提升（Integer Promotion）

小于 int 范围的整型（如 char, short）参与算术运算时，通常先自动提升为 int 参与计算。

规则 2：一般算术转换（Usual Arithmetic）

当两个不同类型的操作数参与双目运算时，低等级类型自动转换为高等级类型，然后执行同精度计算，结果类型为高等级类型。

自动转换和赋值转换，是两个不同阶段

两阶段模型：
阶段一（求值阶段）：表达式内部按最高类型统一计算，低类型单向自动提升；
阶段二（赋值阶段）：计算结果转换为等号左边变量的类型，若目标类型范围或精度较小则可能产生截断。

赋值时发生的小数截断与数据截断

浮点赋值给整型：向零截断

double bmi = 24.89;
int intBMI = bmi;   /* intBMI 变为 24 */

注意：向零截断并非四舍五入。即使是 24.99 赋给整型变量，小数部分也会被直接截去，变为 24。

高位整型赋给低位整型：高位丢弃

int x = 257;        /* 0x00000101 */
char c = x;         /* 只保留低8位 0x01 */

c 的最终数值为 1。超过目标类型可表示范围时，高位字节会被忽略。

认知盲区：整数转换为浮点，也不总是精确的

小整数转浮点：通常精确

如 100 → 100.0，因有效数字位数充裕，可以精确表达。

较大整数转 float：可能损失尾数

int big = 16777217;   /* 2^24 + 1 */
float f = big;
printf("%d\n", (int)f); /* 打印 16777216 */

float 有效数字约为 7 位（尾数 24 位），数值过大时超出有效位数，低位数字会被舍入。

较大整数（如身份证号、纳秒级时间戳）如果需要转为浮点数，建议选用有效位数更多的 double。

6.2 / 格式化I/O与内存类型
占位符与内存解释：
类型匹配与格式速查
掌握各种进制整数、浮点数与字符的格式控制符，理解 scanf 传址与内存写入机制。
scanf 取地址 & 进制格式符 (%d / %o / %x) 实数与字符 (%f / %lf / %c) 字段宽度与精度

看的是值，还是地址？scanf 漏写 & 的后果

常见错误：scanf 漏写取地址符 &

int sbp = 120;
scanf("%d", sbp);   /* 错误写法：传入了数值 120 */

这里传入的是变量当前的值 120，scanf 会将 120 视作目标内存地址尝试写入，通常会引发段错误（Segmentation Fault）导致程序异常终止。

正确写法：传入变量的地址

int sbp;
scanf("%d", &sbp);  /* 正确传递地址 */

&sbp 表示变量在内存中的地址，scanf 通过该地址将键盘读入的数据写入到 sbp 对应的存储单元中。

整型数据与各进位制格式控制符速查

格式控制符 匹配数据类型 进位制与显示特征 printf 示例（设 n = 95） scanf 输入与说明
%d / %i int 有符号十进制整数 printf("%d", n); → 95 标准十进制整型输入：scanf("%d", &n);
%u unsigned int 无符号十进制整数 printf("%u", n); → 95 用于非负整数（如计数、大小、下标）
%o / %#o int / unsigned 八进制（# 自动输出前缀 0） printf("%#o", n); → 0137 按八进制读入，输入 0137 实际解析为 95
%x / %#x int / unsigned 十六进制小写（# 加前缀 0x） printf("%#x", n); → 0x5f 常用在位运算、颜色编码与内存数据查看
%X / %#X int / unsigned 十六进制大写（# 加前缀 0X） printf("%#X", n); → 0X5F 以大写字母（A~F）输出十六进制
%hd / %hu short / unsigned short 短整型（2 字节） printf("%hd", s); 必须加 h：scanf("%hd", &s);
%ld / %lu long / unsigned long 长整型（4 或 8 字节） printf("%ld", l); 必须加 l：scanf("%ld", &l);
%lld / %llu long long / unsigned ... 超长整型（标准 8 字节，64 位） printf("%lld", ll); 必须加 ll：scanf("%lld", &ll);
进制输出小提示：使用 %#o 和 %#x 可以让编译器自动输出 0 和 0x 前缀，与 C 语言整数字面常量的写法完全一致，便于查验和对比。

实数、字符与特殊类型格式控制符速查

格式控制符 匹配数据类型 含义与输出特征 printf 行为与示例 scanf 规则与要点
%f float (单精度, 4B) 单精度浮点数 默认输出 6 位小数：3.140000 float 输入必须严格用 %f
%lf double (双精度, 8B) 双精度浮点数 printf 中 %f 与 %lf 通用 double 输入必须严格用 %lf
%e / %E float / double 科学计数法指数形式 printf("%e", 123.45); → 1.234500e+02 输入可识别 1.23e2 等科学计数法格式
%g / %G float / double 自适应紧凑输出 自动选 %f 或 %e 简短者，去掉多余尾随0 常用于美化输出（如输出 3.5 而非 3.500000）
%c char (1 字节) 单个字符 输出对应字符：printf("%c", 'A'); 不跳过空白符，读取前建议加空格：" %c"
%s char[] / 字符串 以 '\0' 结尾的字符串 连续输出字符直到遇到 '\0' 遇空格或换行终止，数组名即地址，不加 &
%p 指针 / 地址值 变量在内存中的十六进制地址 printf("%p", (void*)&n); 用于观察变量或指针在内存中的物理位置
%% 无操作数 输出一个字符 % printf("完成率: 98%%\n"); 因 % 为引导符，连续两个 %% 转义为一个 %
关键区分：对于 double 类型，printf 输出时 %f 和 %lf 均可（C99起统一）；但在 scanf 输入时，必须严格区分：float 必须对应 %f，double 必须对应 %lf！

深入理解：float 与 double 的输入输出机制

函数与场景 float (单精度 4 字节) double (双精度 8 字节) 底层原理与混淆后果
printf 输出 %f %f 或 %lf（均可） 在 C 语言可变参数中，float 参数会自动提升为 double 传递，因此 %f 完全通用
scanf 输入 必须用 %f 必须用 %lf 类型必须严格匹配：scanf 需根据说明符向指针写入 4 字节还是 8 字节，混用会导致数据损坏或越界

常见典型错误

double bmi;
scanf("%f", &bmi);    /* 错误写法 */

%f 会指示 scanf 仅写入 4 字节内存，而 bmi 是 8 字节变量，导致高位未写入或数值解析完全错误。

标准规范写法

double bmi;
scanf("%lf", &bmi);   /* 正确写法 */

使用 %lf 保证完整写入 8 字节 IEEE-754 双精度浮点格式，数值准确无误。

读取字符时的缓冲区换行符问题

常见现象：字符被换行符跳过

int age;
char gender;
scanf("%d", &age);
scanf("%c", &gender); /* 读入了前序回车换行符 '\n' */

输入年龄后敲击回车产生的 '\n' 残留在输入缓冲区中，紧随其后的 %c 不会等待输入，而是直接将其读入。

解决方法：在 %c 前加空格

int age;
char gender;
scanf("%d", &age);
scanf(" %c", &gender); /* 空格跳过空白符 */

格式串中的空格会让 scanf 自动跳过缓冲区中残留的所有连续空白符（包括换行符、空格与制表符）。

格式附加修饰符：宽度、对齐与精度控制速查

修饰符语法 功能描述 代码示例 实际屏幕输出效果
%md（如 %5d） 指定最小输出宽度为 m 列（默认右对齐，不足补空格） printf("[%5d]", 42); [   42]（前补 3 个空格）
%-md（如 %-5d） 指定最小宽度并强制左对齐（不足右侧补空格） printf("[%-5d]", 42); [42   ]（后补 3 个空格）
%0md（如 %04d） 指定最小宽度，不足时在前面补数字 0 printf("%04d-%02d", 2026, 9); 2026-09（常用于日期、时钟、编号）
%.nf（如 %.2f） 指定浮点数保留的小数位数（四舍五入） printf("%.2f", 3.14159); 3.14
%m.nf（如 %8.2f） 同时指定总宽度 m 与小数位数 n printf("[%8.2f]", 3.14); [    3.14]（总宽 8 位，含小数点和小数）
核心辨析：printf("%.2f", bmi); 仅改变屏幕显示形式，变量 bmi 在内存中的二进制高精度数据并未改变，参与后续运算仍保持原有精度。
6.2 / 优先级、结合性与副作用
算术运算规则与括号使用
运算符具有优先级与结合方向，合理使用圆括号可以使求值顺序清晰明确。
优先级分层 结合方向 前置++ vs 后置++ 复合赋值

算术表达式：先乘除，后加减

常用优先级层次

  1. 初等运算符：圆括号 ()、数组成员
  2. 单目运算符：!, ++, --, (type)
  3. 算术运算符：乘除模 * / % 高于 加减 + -
  4. 关系运算符：< <= > >= 高于 == !=
  5. 逻辑运算符：&& 高于 ||
  6. 条件运算符：三目 ? :
  7. 赋值运算符：= += -= *=
  8. 逗号运算符：,（最低）

实用编程建议

在表达式较长或运算符较多时，不必强记全部优先级细节。

当对求值次序不够确定时，建议使用圆括号 () 明确结合关系。

前置 ++ 与后置 ++：变量都加1，但表达式值不同

前置自增：++a（先加后用）

变量 a 先自增 1，然后以新值作为表达式的返回值参与后续运算或赋值。

后置自增：a++（先用后加）

以 a 的原有值副本作为表达式返回值，随后变量 a 在内存中自增 1。

复合赋值：表达更新，注意类型转换

语法展开说明

a += b; 等价于 a = (目标类型)(a + b);

包含 +=, -=, *=, /=, %=。书写简洁，表示对变量的原位更新。

复合赋值中的类型截断

int count = 10;
count *= 1.5;   /* 相当于 count = (int)(10 * 1.5) = 15 */

复合赋值会将右侧运算结果自动转换为左侧变量的类型，若目标类型精度较低可能会丢失小数部分。

综合例题：函数 + 循环 + 类型转换实战

#include <stdio.h>

double calculateAverage(int sum, int count) {
    if (count <= 0) {
        return -1.0;   /* 检查除数是否有效 */
    }
    return (double)sum / count;   /* 确保执行浮点除法 */
}

int main(void) {
    int sbpSum = 0, count = 0, sbp;
    while (scanf("%d", &sbp) == 1 && sbp >= 0) {
        sbpSum += sbp;
        count++;
    }
    printf("有效随访数: %d | 平均收缩压: %.2f mmHg\n", count, calculateAverage(sbpSum, count));
    return 0;
}
将数据校验、累加更新与均值计算分离，逻辑更清晰，易于测试与复用。

第2课时核心结论

  • 两个整数相除为整数除法，若需保留小数，应至少有一个浮点操作数
  • 强制类型转换应直接作用于操作数：(double)a / b，避免外层括号
  • scanf 读取需传入变量地址 &，读取 double 需用 %lf
  • 赋值给整型变量会发生向零截断；分清前置与后置自增的区别
